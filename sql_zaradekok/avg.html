Aggregáló függvény: AVG()

A AVG() függvény egy numerikus oszlop átlagértékét adja vissza.

A AVG() függvény függvény figyelmen kívül hagyja a NULL értékeket az oszlopban.

Példa:

SELECT AVG(Fizetés)

FROM dolgozók;

Látható, hogy az eredménytábla a kiválasztott mezőből áll.

Ilyenkor mindig csak egy sorral (rekord) tér vissza.

Példa:

SELECT AVG(Jutalom)

FROM dolgozók;

Látható, hogy az eredménytábla a kiválasztott mezőből áll.

Ilyenkor mindig csak egy sorral (rekord) tér vissza.

Példa:

SELECT AVG(Fizetés), AVG(Jutalom)

FROM dolgozók;

Látható, hogy az eredménytábla a kiválasztott mezőből áll.

Ilyenkor mindig csak egy sorral (rekord) tér vissza.
