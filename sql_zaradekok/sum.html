Aggregáló függvény: SUM()

A SUM() függvény egy numerikus oszlopban található értékek összegének kiszámítására szolgál.

A SUM() függvény függvény figyelmen kívül hagyja a NULL értékeket az oszlopban.

Példa:

SELECT SUM(Fizetés)

FROM dolgozók;

Látható, hogy az eredménytábla a kiválasztott mezőből áll.

Ilyenkor mindig csak egy sorral (rekord) tér vissza.

Példa:

SELECT SUM(Jutalom)

FROM dolgozók;

Látható, hogy az eredménytábla a kiválasztott mezőből áll.

Ilyenkor mindig csak egy sorral (rekord) tér vissza.

Példa:

SELECT SUM(Fizetés), SUM(Jutalom)

FROM dolgozók;

Látható, hogy az eredménytábla a kiválasztott mezőből áll.

Ilyenkor mindig csak egy sorral (rekord) tér vissza.
